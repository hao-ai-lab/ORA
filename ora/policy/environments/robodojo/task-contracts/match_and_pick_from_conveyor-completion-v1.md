Public completion contract for this task:

- The object that counts is the matching one that comes along the conveyor
  later, a second copy of the first object. Lifting the first object itself, or
  any other object, does not count.
- That matching object must be lifted well up off the conveyor, clearly higher
  than it rode on the belt; a slight lift, or sliding or pushing it along the
  belt, does not count. It counts at the first moment it is that high; it need
  not be held there, carried anywhere or set down afterwards.
- This task does not require the arms to end at their reset poses.

The conveyor belt advances only while robot commands are consuming native
actions; while no robot command executes, the belt does not move.
