Public completion contract for this task:

- The target object is the one shown in the image on the board; no other object
  counts in its place.
- The target object must end up inside the basket, lying on the basket's bottom
  and entirely within it, not hanging over the rim, perched on the edge or held
  up above the bottom.
- At that same moment the basket must be raised, so that the target object lying
  in it is higher than it was when the episode reset by more than the lift
  height the task instruction names. A basket lifted while still empty and set
  down again before the object is in it does not count.
- This task does not require the arms to end at their reset poses.

The conveyor belt advances only while robot commands are consuming native
actions; while no robot command executes, the belt does not move.
